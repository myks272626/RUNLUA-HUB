RUNLUA UI LIBRARY — แอดมินแจกฟรีสำหรับทุกคนนะครับ เข้าใจง่ายๆเลย By RUNLUA HUB THAI
=============================================

เอกสารนี้มีไว้สำหรับ AI ที่ต้องเขียน/แก้ Script ให้เข้ากับ RUNLUA UI Library
ให้ถือ API ในเอกสารนี้เป็น API หลักของ Library และห้ามสมมติ API ของ Library อื่น
เช่น Rayfield, Fluent, Linoria, Kavo หรือ Vape

RAW LIBRARY
-----------
ไฟล์ Library:
Library UI/MAIN/RUNLUA_UI_Library.lua

รูปแบบการโหลด:
local Library = loadstring(game:HttpGet("YOUR_RAW_LIBRARY_URL"))()

จากนั้นสร้าง Window:
local Window = Library:CreateWindow({
    Title = "RUNLUA HUB",
    Subtitle = "UI Library",
})

สำคัญ:
- Library คืนค่า table ชื่อ Library
- Window คืนค่า Window object
- Tab คืนค่า Tab object
- Component ต่าง ๆ คืนค่า API object ตามที่ระบุด้านล่าง
- โค้ดของ UI ต้องทำงานผ่าน API ของ Library นี้
- อย่าสร้างระบบ UI ใหม่ทับ Library หากผู้ใช้ไม่ได้ขอ
- อย่าเปลี่ยน Library เป็น UI framework อื่น
- อย่าใช้ Emoji เป็น Icon หากมี Icon API ให้ใช้ Library.Icons

Library:CreateWindow() -> Window

============================================================

local Window = Library:CreateWindow({
    Name = "RUNLUA_UI",
    Title = "RUNLUA HUB",
    Subtitle = "Professional UI",
    Logo = "",

    Config = {
        WindowSize = Vector2.new(460, 330),
        WindowMinSize = Vector2.new(320, 240),

        SidebarWidth = 118,
        SidebarWidthCompact = 48,
        CompactBreakpoint = 480,

        HeaderHeight = 40,
        RowHeight = 34,
        RowHeightDesc = 46,
        RowSpacing = 5,
        Padding = 10,
        CornerRadius = 9,

        AnimFast = 0.15,
        AnimNormal = 0.22,
        AnimSlow = 0.35,

        MaxNotifications = 4,
        NotificationWidth = 240,
        NotificationRight = 20,
        NotificationTop = 20,
    },

    Theme = {
        Background = Color3.fromRGB(10, 16, 32),
        Surface = Color3.fromRGB(18, 28, 50),
        SurfaceAlt = Color3.fromRGB(24, 36, 60),
        SurfaceHover = Color3.fromRGB(30, 44, 74),

        Accent = Color3.fromRGB(0, 132, 255),
        AccentSoft = Color3.fromRGB(0, 90, 190),
        AccentLight = Color3.fromRGB(90, 180, 255),

        Text = Color3.fromRGB(232, 240, 255),
        TextMuted = Color3.fromRGB(140, 160, 200),
        Border = Color3.fromRGB(38, 60, 105),

        Success = Color3.fromRGB(0, 180, 120),
        Danger = Color3.fromRGB(220, 60, 80),
        Warning = Color3.fromRGB(240, 180, 60),

        SwitchOff = Color3.fromRGB(40, 52, 76),
        Shadow = Color3.fromRGB(0, 0, 0),

หมายเหตุ:
- ค่า Config/Theme เป็น optional
- ถ้าต้องการเปลี่ยนขนาด Window ให้ใช้ Config.WindowSize
- ระบบมี responsive/mobile mode อยู่แล้ว
- อย่าทำ UI Scale หรือ Mobile layout ใหม่ทับ Library โดยไม่จำเป็น

    Name = "Enabled",
    Description = "Example switch",
    Icon = Library.Icons.Settings,

    Default = false,

    Callback = function(value)
        print("Enabled:", value)
    end,
})

อ่านค่า:
local value = Toggle:Get()

ตั้งค่า:
Toggle:Set(true)

ตั้งค่าและเรียก Callback:
Toggle:Set(false, true)

Alias:
Toggle:SetValue(true, true)

Callback:
function(value)
    -- value เป็น boolean
end

11. DROPDOWN
============================================================

local Dropdown = Main:Dropdown({
    Name = "Mode",
    Description = "Select a mode",

    Values = {
        "Option 1",
        "Option 2",
        "Option 3",
    },

    Default = "Option 1",

    Callback = function(value)
        print("Selected:", value)
    end,
})

อ่าน:
Dropdown:Get()

เปลี่ยนค่า:
Dropdown:Set("Option 2")

เปลี่ยน + Callback:
Dropdown:Set("Option 3", true)

เปลี่ยนรายการ:
Dropdown:Refresh({
    "A",
    "B",
    "C",
})

ปิด:
Dropdown:Close()

รองรับชื่อ field:
Values = {...}
หรือ:
Options = {...}

12. TEXTBOX
============================================================

local Textbox = Main:Textbox({
    Name = "Username",
    Description = "Enter username",
    Placeholder = "Type here...",
    Default = "",
    ClearOnFocus = false,

    Callback = function(text, enterPressed)
        print(text)
        print(enterPressed)
    end,
})

อ่าน:
Textbox:Get()

ตั้ง:
Textbox:Set("Hello")

ตั้ง + Callback:
Textbox:Set("Hello", true)

เข้าถึง TextBox ตัวจริง:
Textbox.TextBox

เช่น:
Textbox.TextBox.Text = "Direct edit"

Callback arguments:
text = string
enterPressed = boolean

13. KEYBIND
============================================================

local Keybind = Main:Keybind({
    Name = "Toggle UI",
    Description = "Press a key",

    Default = Enum.KeyCode.RightControl,

    Callback = function(key)
        print("Pressed:", key.Name)
    end,

    Changed = function(newKey)
        print("Changed:", newKey.Name)
    end,
})

อ่าน:
Keybind:Get()

เปลี่ยน:
Keybind:Set(Enum.KeyCode.LeftControl)

เมื่อกดปุ่ม Keybind ใน UI:
- Library จะเข้า listening mode
- ให้ผู้ใช้กด Keyboard key
- Keybind จะเปลี่ยนเป็น key ใหม่
- Changed callback จะถูกเรียก

21. กฎสำหรับ AI ที่นำ Library ไปใช้
============================================================

1. ใช้ Library นี้โดยตรง:
   Library -> Window -> Tab -> Component

2. ห้ามเปลี่ยนไปใช้ UI Library อื่นโดยไม่ได้รับคำสั่ง

3. ห้ามสมมติ Method ที่ไม่มีในเอกสารนี้

4. Toggle Callback รับ boolean

5. Slider Callback รับ number

6. Dropdown Callback รับ selected value

7. Textbox Callback รับ text และ enterPressed

8. Keybind Callback รับ KeyCode

9. PlayerList OnSelect รับ Player object

10. Button Callback ไม่มี argument

11. ใช้ Library.Icons สำหรับ Icon

12. หากต้องการซ่อน/เปิด Window:
       Window:Hide()
       Window:Show()
       Window:Toggle()

13. หากต้องการลบ Window:
       Window:Destroy()

14. อย่าสร้าง ScreenGui/Sidebar/Toggle system ใหม่เพื่อแทนระบบของ Library
    เว้นแต่ผู้ใช้สั่งให้แก้ Library โดยตรง

15. UI ควรคำนึงถึงมือถือ เพราะ Library มี responsive mode และ Touch support

16. เมื่อเขียนโค้ดให้ Library:
    - ใช้ Colon syntax กับ Method:
        Window:CreateTab(...)
        Main:Toggle(...)
    - อย่าเปลี่ยนเป็น:
        Window.CreateTab(...)
      เว้นแต่มีเหตุผลทาง Lua ที่จำเป็น

17. อย่าใส่ Markdown fence ลงในไฟล์ RAW ของ Library
